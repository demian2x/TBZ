# Recap Tabelle

Ausgefüllte Lücken im Dokument "Tabellenterminologie" (Beispiel: Tabelle Personen mit PNr, Name, Vorname, Geschlecht).

| Element im Bild                        | Begriff                               |
|--------------------------------------------|-------------------------------------------|
| Die ganze Tabelle "Personen"               | Tabelle / Relation / Entität(styp)        |
| Tabellenname "Personen"                    | Entitätsname                              |
| Kopfzeile (PNr, Name, Vorname, Geschlecht) | Attribute / Spaltennamen (Tabellenschema) |
| Eine Zeile, z. B. 1234 Müller Ernst m      | Datensatz / Tupel / Entität               |
| Eine Spalte, z. B. alle Vornamen           | Attribut / Feld                           |
| Eine einzelne Zelle, z. B. "Hans"          | Attributwert                              |
| Spalte PNr                                 | Primärschlüssel (Primary Key)             |
| Anzahl Zeilen                              | Kardinalität der Relation                 |
